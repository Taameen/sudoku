# sudoku
Перед вами небольшой проект, в котором реализован алгоритм создания судоку, а также графическая оболочка, для вывода удобного изображения для печати

Судоку - это занимательная головоломка с числами, в которой необходимо заполнить недостающими числами клетки игрового поля 9 на 9. Часть цифр изначально вписана в клетки. Они и служат отправной точкой для решения данной головоломки

Основные правила судоку:
1. Цифра может появиться только один раз в каждой строчке
2. Цифра может появиться только один раз в каждом столбце
3. Цифра может появиться только один раз в каждом секторе (квадрат 3 на 3)

Из чего состоит судоку:
> Поле (или сектка) - основной квадрат клеток, размером 9 на 9. Поле поделено на 9 секторов 3 на 3.
> Клетка - одна ячейка поля, в которую вписывают цифру. Всего на поле 81 клетка.
> Строка - горизонтальный ряд клеток от 1 до 9. Поле состоит из 9 строк.
> Столбец - вертикальный ряд клеток от 1 до 9. Поле состоит из 9 столбцов.

Алгоритм состоит из 3 основных шагов:
1. Базовая сетка.
2. Перетасовка сетки.
3. Удаление клеток.
